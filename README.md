# jQuery Game (aka 'Memory Game')
### What is it?
A small 'match the cards' memory game I originally built when I was learning about jQuery.
At a later date I improved upon it by incorporating Bootstrap (when I learnt about that).
This made the design more responsive to different screen sizes.<br>

### Status?
Fully functional.<br>

### Further Improvements?
If the screen width goes beyond 768 pixels, the user has to scroll up and down to be able to view the upper/lower parts of the card grid.
Therefore a media query or bootstrap rule could be made to help keep the whole grid on screen.<br>
